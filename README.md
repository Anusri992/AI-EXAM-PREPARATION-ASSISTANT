# AI Exam Preparation Assistant (Streamlit + Groq)

    pip install -r requirements.txt
    # rename .env.example to .env and paste your GROQ_API_KEY
    streamlit run app.py

Users register themselves, then use: Dashboard, Doubt Solver, Study Plan,
Question Generator, Mock Tests, Analytics, Documents, Profile.
Data is stored in examprep.db (SQLite).
